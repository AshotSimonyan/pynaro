# Pynaro Mobile

Expo + Expo Router app for the customer and technician roles. Business dispatch
and admin live in the separate Next.js dashboard.

- Architecture: [`docs/architecture.md`](docs/architecture.md)
- Step plan: [`docs/implementation-plan.md`](docs/implementation-plan.md)
- Working agreement and hard rules: [`CLAUDE.md`](CLAUDE.md)

## Requirements

Node >= 22.13, pnpm, Xcode with CocoaPods (iOS), Android Studio (Android).
There is no Expo Go phase: `react-native-maps` and background location need
native code, so the app runs on a custom dev client from day one.

## Running

```sh
pnpm install
APP_VARIANT=development pnpm prebuild   # regenerates ios/ and android/
pnpm ios                                # builds the dev client and boots it
pnpm start                              # Metro, once the dev client is installed
```

`ios/` and `android/` are generated by prebuild and are not committed. Change
native config in `app.config.ts`, never in the generated projects.

## Variants

`APP_VARIANT` selects the build. It defaults to `development` and fails loudly
on an unknown value.

| APP_VARIANT | Name            | Bundle id               | Scheme           | Channel      |
| ----------- | --------------- | ----------------------- | ---------------- | ------------ |
| development | Pynaro Dev      | `co.pynaro.app.dev`     | `pynaro-dev`     | —            |
| staging     | Pynaro Staging  | `co.pynaro.app.staging` | `pynaro-staging` | `staging`    |
| production  | Pynaro          | `co.pynaro.app`         | `pynaro`         | `production` |

Runtime values come from `expo-constants` `extra` via `src/lib/config.ts`, never
from `process.env` at runtime. Copy `.env.example` to `.env` for local work.

## Checks

```sh
pnpm typecheck
pnpm lint
pnpm format:check
```

## Layout

```
app/          routes only, the tree in §2 of the architecture doc
src/api/      the data contract; the adapter is chosen here and nowhere else
src/theme/    tokens; no literal hex in a component
src/domain/   the transition table, driving affordances only
src/stores/   session, request draft, map UI
src/lib/      config and small shared helpers
reference/    the React prototype, UI and UX reference only
```

Nothing above `src/api` may know which adapter is running. ESLint enforces it.
